# HCM Lite - AI Assisted Human Capital Management

MERN Stack (MongoDB, Express, React, Node.js)

## Quick Start

### Backend
`ash
cd Backend
cp .env.example .env
npm install
npm run dev
`

### Frontend
`ash
cd frontend
npm install
npm run dev
`

## First Run
1. Open app - will redirect to First Run Setup
2. Set company name and create Admin account
3. Login as Admin, configure org settings, create HR, register employees

## Features
- Auth & RBAC (Admin/HR/Employee)
- Organization Setup
- Employees Directory
- Attendance (Check-in/Check-out)
- Leave Management
- Payroll Lite
- Dashboards & Analytics
- AI Assistant (Chat, Smart Leave)
- Comms & Audit Log

## Tech
Backend: Express, Mongoose, JWT, bcryptjs
Frontend: React, Vite, Tailwind CSS, React Router, Axios, Recharts

Demo ready for Saylani Hackathon.
